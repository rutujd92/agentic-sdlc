Agentic SDLC Orchestrator: demo runs

Reports generated from real runs of the orchestrator. Each shows the dependency graph, reliability metrics, human decisions, policy findings, the full audit timeline and every artifact (requirements, design, code diffs, validation report).

Greenfield: QR code endpoint

Parallel agents; a lane violation retried with the rejection as feedback; a new dependency (QRCoder, MIT) paused for review; real build and 78 tests; merge approval.

Brownfield: click analytics

Cross-layer change. Design re-plans and adds a migration step generated by dotnet ef, approved twice (plan, then generated files); real build and 80 tests.

Brownfield: migration rejected

A human rejects the migration: downstream steps are skipped and the workspace rolls back to the last green checkpoint.

Ambiguous: "Make the links safer."

Requirements raise three open questions and the run pauses; a human clarification re-runs requirements and the pipeline; operator stop during validation, then resume.
Source, setup and engineering summary: github.com/rutujd92/agentic-sdlc. Agent responses in these runs were hand-authored replays (see the README); validation, builds, tests, migrations and governance ran for real.
